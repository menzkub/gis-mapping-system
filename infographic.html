วิวัฒนาการของระบบ
1
เริ่มต้น · ต้นแบบ
v1.0 — Static HTML Prototype
เริ่มต้นเป็น HTML ไฟล์เดียว ใช้ Leaflet.js แสดงแผนที่เปล่าบน GitHub Pages ข้อมูลหม้อแปลงถูก hardcode เป็น GeoJSON ในไฟล์ JS ไม่มีระบบล็อกอิน ไม่มีฐานข้อมูล ใช้เพื่อทดสอบการแสดงผลบนแผนที่เท่านั้น
HTML/CSS/JS Leaflet.js GitHub Pages GeoJSON (hardcode)
2
v1.5 · เพิ่มฐานข้อมูล
v1.5 — Supabase Integration
เชื่อมต่อ Supabase เป็นครั้งแรก ย้ายข้อมูลหม้อแปลงและมิเตอร์ขึ้น PostgreSQL เพิ่มระบบ Authentication เบื้องต้น สามารถ Query ข้อมูลจริงได้ เริ่มรองรับการกรองข้อมูลตาม feeder และ owner บนแผนที่
Supabase PostgreSQL 15 Auth Row-Level Security
3
v2.0 · React & Component
v2.0 — React UMD Architecture
ปรับสถาปัตยกรรมมาใช้ React 18 UMD + Babel Standalone ทั้งหมด ไม่ต้อง build step — browser compile JSX โดยตรง แยก Component ออกเป็น MapView · SearchView · AdminPanel เพิ่มระบบภาษา (Thai/English) ผ่าน lang.jsx เพิ่ม PWA: Service Worker + manifest + ไอคอน
React 18 UMD Babel Standalone PWA Service Worker Multi-language
4
v2.5 · Security & Admin
v2.5 — 2FA + Admin Dashboard
เพิ่มระบบ 2FA/MFA ด้วย TOTP (Time-based One-Time Password) สร้าง Admin Panel พร้อม Dashboard แสดงสถิติข้อมูลแบบ Real-time เพิ่ม Push Notification ผ่าน Web Push API GitHub Actions CI/CD สำหรับ deploy อัตโนมัติ StatCard · Donut Chart · Top Feeder ranking
2FA/MFA · TOTP Admin Dashboard Push Notifications CI/CD GitHub Actions
✦
v3.1 · ปัจจุบัน
CURRENT
v3.1 — Full-Featured GIS Platform
ระบบ GIS เต็มรูปแบบ ครอบคลุมการจัดการมิเตอร์ >55,000 รายการ และหม้อแปลง >1,700 เครื่อง พร้อม Dashboard วิเคราะห์ข้อมูลเชิงลึก รองรับการทำงานแบบ Offline (PWA Cache-first), ระบบ Search ขั้นสูง, Supabase RPC สำหรับ Aggregate Stats, ระบบ Settings แบบ Dynamic, Multi-role User Management และ "Powered By" Tech showcase

System Flow
การทำงานของระบบ
👤 ผู้ใช้งาน
🌐
เปิดเว็บ / PWA
เข้าใช้งานผ่าน Browser หรือติดตั้งเป็น PWA บนมือถือ — Service Worker โหลด Cache ทันที แม้ไม่มี Internet
🔐
Login + 2FA
ยืนยันตัวตนด้วย Email/Password + รหัส TOTP (6 หลัก) ผ่าน Supabase Auth — JWT token ใช้สำหรับ Request ทุกรายการ
🗺️
Map View
แผนที่แบบ Interactive แสดง Marker มิเตอร์และหม้อแปลง — กรองตาม feeder, owner, ประเภท — คลิกดูรายละเอียดได้ทันที
🔍
Search View
ค้นหามิเตอร์/หม้อแปลงด้วยรหัส, ที่อยู่, feeder — แสดงผลแบบ List พร้อมปุ่ม Focus บนแผนที่
⚛️ แอปพลิเคชัน
📦
React 18 UMD
Browser compile JSX ด้วย Babel Standalone — ไม่มี build step, โหลดจาก CDN ตรง — app.jsx เป็น Entry Point หลัก
🧩
Component Layer
components.jsx · MapView.jsx · SearchView.jsx · AdminPanel.jsx · AuthScreen.jsx — แต่ละ View แยก Logic อิสระ
🌍
Leaflet.js Map
Tile layer จาก OpenStreetMap — Marker Clustering, Popup Info, Layer Control สำหรับกรองประเภทข้อมูล
⚡
Service Worker v15
Cache-first strategy สำหรับ Static Assets — Network-only สำหรับ Supabase — Push Notification listener
🗄️ Backend / Data
🟢
Supabase
PostgreSQL 15 + Auth + RLS + Realtime — เป็น BaaS หลักของระบบ — Auto REST API ผ่าน PostgREST
📊
RPC Functions
get_dashboard_stats() — plpgsql SECURITY DEFINER ดึง Aggregate Stats: meter_count, tr_count, kva, feeders — คืนค่าเป็น JSON
🔒
Row-Level Security
Policy ควบคุมว่า User แต่ละ Role เห็นข้อมูลอะไรได้บ้าง — Admin เห็นทั้งหมด, User ทั่วไปเห็นเฉพาะ View
🚀
GitHub Pages + CI/CD
GitHub Actions deploy อัตโนมัติเมื่อ push ไป main branch — Hosting ฟรี, HTTPS อัตโนมัติ, Global CDN
